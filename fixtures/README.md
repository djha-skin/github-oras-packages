# Deterministic package and OCI fixtures

This directory is the source of truth for the small, synthetic fixture corpus
used by proxy and OCI resolver tests. It contains no third-party source,
credentials, private keys, or downloaded artifacts. The package name
`capturepkg` and repository `acme/fixture` are reserved test values.

## Rebuild and verify

From the repository root:

```sh
python3 fixtures/generate.py
python3 fixtures/verify.py
```

`generate.py` uses only the Python standard library and replaces
`fixtures/corpus` deterministically. It writes:

* a wheel and source distribution for PyPI;
* an unsigned, structurally valid RPM v3 package with deterministic header,
  payload, and file digests for RPM-MD tests;
* a Debian binary package containing a gzip-compressed control and data
  archive;
* an Arch package and sync database using deterministic raw-block zstd;
* a legacy OCI image-layout-compatible manifest, config, route map, and
  content-addressed blobs for migration tests; the running autoindex fixture
  projects ordinary package files into standard OCI descriptor titles; and
* independent malformed manifest/route-map/blob/metadata cases for negative
  tests, including duplicate routes, foreign URLs, unsupported versions,
  missing content, checksum mismatch, and invalid descriptors.

The generated bytes are deliberately tiny. Every blob filename is its
lowercase SHA-256 digest, and the generator checks that invariant before it
returns. Native metadata names and checksums refer only to paths in the same
public `acme/fixture` repository; there are no external URLs or repository
references. PyPI links are absolute proxy-local routes so a client cannot
reinterpret a relative link against a different base.

The baseline corpus is unsigned (`fixture-index.json` records
`signaturePolicy: unsigned-base-fixture`). This is intentional: tests for
transport, descriptor integrity, and exact route mapping must not require a
local signing key. Signature-required publisher and client scenarios should
add separately generated public test keys and sidecars rather than treating
these redistributable fixture bytes as signed artifacts. The RPM has no
OpenPGP signature; `rpm -qp` validates its package header and payload listing.

The route map uses the public locator `YWNtZS9maXh0dXJl` and the immutable
publication tag `oras-packages.v1`. `manifest.json`, `config.json`, and
`route-map.json` are convenient decoded copies; the corresponding content
addressed versions are in `blobs/sha256/`.
